## Run it

```sh
python3 poster.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`poster.py` draws the newspaper page (`entry.png`, 1024x1024) from verified 23 November 2026 news research using Pillow. `main.ts` (Node 22, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` for grading.
